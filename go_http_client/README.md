# Go HTTP Client

This project is a simple Go program that sends an HTTP GET request to a sample API and prints the response.

## Prerequisites

- Go (version 1.x or later)

## Running the Program

To run the program, navigate to the `go_http_client` directory and use the following command:

```sh
go run main.go
```

This will execute the `main` function in `main.go`, which sends a request to `https://jsonplaceholder.typicode.com/todos/1` and prints its status code and body.

## Running Tests

To run the tests, navigate to the `go_http_client` directory and use the following command:

```sh
go test
```

This will execute the tests defined in `main_test.go`.
